# EU Banking Compliance Checker Samples

Presentation and interface samples for an explainable compliance review workflow in the EU banking context, assuming NatWest as the client.

- `PROBLEM-STATEMENT.md` — presentation-ready problem statement, scope assumptions, workflow, and traceability requirements.
- `sample-audit-report.html` — interactive report sample with HR, Legal and Finance domain filters, findings, and navigable policy-to-evidence decision trails.

The HTML report uses illustrative data and links to official source landing pages as examples. Its findings and citations are not validated NatWest compliance conclusions. A production implementation should use verified source documents and provisions and real internal evidence.
